# Ilustrações dos heróis

Instruções prontas para gerar as ilustrações num gerador de imagem, todas no mesmo estilo.
Não precisa fazer as 43: cada herói ilustrado usa a imagem, o resto continua com o boneco
desenhado por código. Comece pelos Lendários, que aparecem mais.

## Como usar cada imagem

1. Gere a imagem com a instrução do herói (uma por vez).
2. Salve como **PNG com fundo transparente**, quadrado, 512×512, com o nome do id do herói —
   por exemplo `salomao.png` — dentro de `alianca/arte/`.
3. Acrescente o id na lista de `alianca/arte/lista.js`.

O jogo recorta as margens vazias sozinho e ajusta o tamanho, então não precisa acertar o
enquadramento na mão. Imagem **sem** fundo transparente ainda serve de retrato no elenco,
mas a batalha segue com o boneco desenhado, para não virar um retângulo flutuando no campo.

## Estilo comum a todas

```
16-bit pixel art character, full body, front view, standing idle pose, thick dark outline, limited palette with 3 to 4 shades per material, soft light from the upper left, gold trim and gemstone accents, clean readable silhouette, crisp pixels, no anti-aliasing, character centered and filling about 85% of the frame with the feet near the bottom, transparent background, no card frame, no border, no text, no name label, no stars, no ground shadow
```
